# Controller

## Назначение (Purpose)

Класс `Controller` является центральным управляющим компонентом системы сортировки. Координирует взаимодействие между всеми элементами системы, принимает решения о дальнейшей обработке товаров и обеспечивает корректную работу сортировочной линии.

---

## Ответственность (Responsibilities)

Класс `Controller` отвечает за:

- управление процессом сортировки;
- получение информации от оборудования;
- обработку событий системы;
- взаимодействие с WMS;
- назначение маршрутов товарам;
- управление конвейерами;
- управление буферами;
- обработку ошибок;
- передачу товаров на ручную обработку;
- регистрацию событий системы.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `wms` | WMS | Экземпляр системы управления складом |
| `conveyors` | list[Conveyor] | Все конвейеры системы |
| `buffers` | list[Buffer] | Буферы хранения |
| `output_bins` | list[OutputBin] | Выходные контейнеры |
| `statistics` | Statistics | Система статистики |
| `scanner` | Scanner | Сканер штрихкодов |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `register_item()` | Регистрация нового товара |
| `request_route()` | Запрос направления у WMS |
| `route_item()` | Назначение маршрута товару |
| `handle_scan_error()` | Обработка ошибки сканирования |
| `send_to_buffer()` | Отправка товара в буфер |
| `send_to_manual_processing()` | Передача товара на ручную обработку |
| `update_statistics()` | Обновление статистики |
| `process_sensor_event()` | Обработка сигнала датчика |

---

## Взаимодействие

### Получает данные от

- Scanner
- Sensor
- Conveyor
- Buffer
- OutputBin

### Передает данные

- WMS
- Conveyor
- Buffer
- Statistics
- Item

---

## Алгоритм работы

1. Получает сигнал о новом товаре.
2. Запрашивает сканирование.
3. Получает штрихкод.
4. Отправляет запрос в WMS.
5. Получает направление.
6. Выбирает доступный маршрут.
7. Передает команду конвейеру.
8. Контролирует прохождение товара.
9. Обрабатывает ошибки при необходимости.
10. Обновляет статистику.

---

## Возможные ошибки

- не удалось считать штрихкод;
- отсутствует маршрут;
- заполнен выходной контейнер;
- переполнен буфер;
- недоступен конвейер;
- отсутствует связь с WMS.

---

## Ограничения

Класс `Controller` не должен:

- хранить характеристики товара;
- самостоятельно сканировать штрихкод;
- самостоятельно перемещать товар;
- принимать функции WMS;
- хранить статистику вместо класса Statistics.

---

## Зависимости

Класс использует:

- Item
- Scanner
- Conveyor
- Buffer
- Sensor
- OutputBin
- WMS
- Statistics

---

## Примечания

`Controller` является центральным координатором системы. Он не выполняет физические операции самостоятельно, а организует взаимодействие между всеми компонентами сортировочного комплекса.
