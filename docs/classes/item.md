# Item

## Назначение (Purpose)

Класс `Item` представляет отдельный товар в системе автоматизированной сортировки. Является моделью физического объекта и хранит всю информацию, необходимую для его идентификации, маршрутизации и отслеживания в процессе обработки.

---

## Ответственность (Responsibilities)

Класс `Item` отвечает за:

- хранение информации о товаре;
- хранение уникального идентификатора;
- хранение штрихкода;
- хранение физических характеристик товара;
- хранение текущего состояния;
- хранение текущего местоположения;
- хранение назначенного направления сортировки;
- изменение собственного состояния;
- предоставление информации другим объектам системы.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | int | Уникальный идентификатор товара |
| `barcode` | str | Штрихкод товара |
| `width` | float | Ширина товара |
| `height` | float | Высота товара |
| `length` | float | Длина товара |
| `weight` | float | Масса товара |
| `category` | str | Категория товара |
| `delivery_type` | str | Тип доставки |
| `is_flammable` | bool | Признак горючего товара |
| `status` | ItemStatus | Текущее состояние товара |
| `destination` | int \| None | Назначенный выходной контейнер |
| `location` | str | Текущее местоположение товара |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `change_status()` | Изменяет текущее состояние товара |
| `set_destination()` | Назначает направление сортировки |
| `update_location()` | Обновляет текущее местоположение |
| `get_info()` | Возвращает информацию о товаре |

---

## Ограничения

Класс `Item` не должен:

- принимать решения о маршруте;
- управлять оборудованием;
- выполнять сканирование;
- взаимодействовать с датчиками;
- управлять конвейерами;
- собирать статистику;
- взаимодействовать с контейнерами напрямую.

---

## Зависимости

Для своей работы класс использует:

- `ItemStatus` — перечисление состояний товара;
- стандартные типы Python (`int`, `str`, `float`, `bool`);
- при необходимости модуль `dataclasses` (если будет принято решение использовать его).

---

## Примечания

Класс `Item` является центральной моделью предметной области. Практически все остальные компоненты системы работают с экземплярами этого класса, но не изменяют его внутреннее устройство напрямую, а используют предоставленные методы.
