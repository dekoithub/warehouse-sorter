# Statistics

## Назначение (Purpose)

Класс `Statistics` предназначен для сбора, хранения и анализа статистических данных о работе сортировочной системы. Используется для оценки производительности, обнаружения узких мест и формирования итоговых отчетов симуляции.

---

## Ответственность (Responsibilities)

Класс `Statistics` отвечает за:

- регистрацию событий системы;
- подсчет обработанных товаров;
- подсчет успешно отсортированных товаров;
- регистрацию ошибок;
- учет использования буферов;
- учет загрузки оборудования;
- расчет производительности системы;
- формирование итоговой статистики.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `processed_items` | int | Количество обработанных товаров |
| `sorted_items` | int | Количество успешно отсортированных товаров |
| `scan_errors` | int | Количество ошибок сканирования |
| `routing_errors` | int | Количество ошибок маршрутизации |
| `buffer_usage` | int | Количество использований буфера |
| `conveyor_load` | dict | Загрузка конвейеров |
| `output_bin_load` | dict | Заполненность контейнеров |
| `simulation_time` | float | Время работы симуляции |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `register_processed_item()` | Зарегистрировать обработанный товар |
| `register_sorted_item()` | Зарегистрировать успешную сортировку |
| `register_scan_error()` | Зарегистрировать ошибку сканирования |
| `register_routing_error()` | Зарегистрировать ошибку маршрутизации |
| `register_buffer_usage()` | Зарегистрировать использование буфера |
| `generate_report()` | Сформировать итоговый отчет |
| `reset()` | Очистить статистику |

---

## Взаимодействие

### Получает данные от

- Controller
- Scanner
- Conveyor
- Buffer
- OutputBin
- Sensor

### Передает данные

- Main
- Пользователю
- Файлу отчета

---

## Алгоритм работы

1. Получает события от компонентов системы.
2. Обновляет соответствующие счетчики.
3. Накапливает статистику в течение всей симуляции.
4. По завершении симуляции формирует итоговый отчет.

---

## Возможные ошибки

- потеря события;
- повреждение статистических данных;
- невозможность сформировать отчет.

---

## Ограничения

Класс `Statistics` не должен:

- управлять оборудованием;
- принимать решения;
- изменять состояние товаров;
- взаимодействовать с WMS;
- управлять маршрутизацией.

---

## Зависимости

Класс использует:

- Controller
- Scanner
- Conveyor
- Buffer
- OutputBin
- Sensor

---

## Формируемые показатели

По окончании симуляции класс должен предоставлять информацию о:

- количестве поступивших товаров;
- количестве успешно отсортированных товаров;
- количестве товаров, отправленных на ручную обработку;
- количестве ошибок сканирования;
- количестве ошибок маршрутизации;
- количестве использований буфера;
- средней загрузке конвейеров;
- средней загрузке выходных контейнеров;
- времени работы системы;
- производительности (товаров/сек);
- проценте успешной сортировки.

---

## Примечания

`Statistics` не влияет на работу сортировочной системы. Его единственная задача — наблюдать за происходящими событиями, собирать данные и предоставлять объективную информацию о работе симуляции.
