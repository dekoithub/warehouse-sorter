# OutputBin

## Назначение (Purpose)

Класс `OutputBin` моделирует выходной контейнер сортировочной системы. Предназначен для приема, хранения и учета успешно отсортированных товаров до момента замены контейнера оператором.

---

## Ответственность (Responsibilities)

Класс `OutputBin` отвечает за:

- прием товаров после завершения сортировки;
- хранение товаров;
- учет количества товаров;
- контроль заполненности контейнера;
- уведомление контроллера о заполнении;
- регистрацию операций приема товаров.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `bin_id` | int | Уникальный идентификатор контейнера |
| `capacity` | int | Максимальная вместимость |
| `items` | list[Item] | Товары внутри контейнера |
| `current_load` | int | Текущее количество товаров |
| `status` | OutputBinStatus | Текущее состояние контейнера |
| `is_full` | bool | Признак заполнения контейнера |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `add_item()` | Поместить товар в контейнер |
| `remove_all_items()` | Освободить контейнер |
| `is_available()` | Проверить возможность приема товара |
| `report_status()` | Передать состояние контроллеру |
| `report_full()` | Сообщить о заполнении |

---

## Взаимодействие

### Получает данные от

- Sorter
- Conveyor
- Controller

### Передает данные

- Controller
- Statistics

---

## Алгоритм работы

1. Получает товар.
2. Проверяет наличие свободного места.
3. Добавляет товар в контейнер.
4. Обновляет количество товаров.
5. При заполнении сообщает контроллеру.
6. После замены контейнера очищает содержимое.

---

## Возможные ошибки

- контейнер переполнен;
- невозможно принять товар;
- потеря связи с контроллером.

---

## Ограничения

Класс `OutputBin` не должен:

- выбирать маршрут товара;
- изменять характеристики товара;
- управлять конвейерами;
- взаимодействовать с WMS;
- собирать статистику самостоятельно.

---

## Зависимости

Класс использует:

- Item
- Controller
- Statistics

---

## Примечания

`OutputBin` является конечной точкой маршрута товара. После успешного помещения товара в контейнер процесс автоматической сортировки считается завершенным.
