# WMS

## Назначение (Purpose)

Класс `WMS` моделирует внешнюю систему управления складом (Warehouse Management System). Предназначен для определения направления сортировки товара на основании его идентификатора или штрихкода и передачи этой информации контроллеру.

---

## Ответственность (Responsibilities)

Класс `WMS` отвечает за:

- регистрацию направлений сортировки;
- хранение правил маршрутизации;
- определение направления товара;
- обработку запросов от контроллера;
- возврат информации о маршруте;
- уведомление об ошибках маршрутизации.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `routes` | dict | Таблица маршрутов |
| `available_destinations` | list[int] | Доступные направления |
| `request_count` | int | Количество обработанных запросов |
| `status` | WMSStatus | Текущее состояние системы |
| `is_available` | bool | Доступность WMS |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `register_route()` | Зарегистрировать маршрут |
| `get_destination()` | Вернуть направление товара |
| `remove_route()` | Удалить маршрут |
| `is_destination_available()` | Проверить доступность направления |
| `report_status()` | Вернуть состояние WMS |

---

## Алгоритм работы

1. Получает запрос от контроллера.
2. Анализирует идентификатор товара.
3. Определяет направление сортировки.
4. Возвращает направление контроллеру.
5. При отсутствии маршрута сообщает об ошибке.

---

## Возможные ошибки

- маршрут не найден;
- направление недоступно;
- отсутствует связь с контроллером;
- WMS временно недоступна.

---

## Ограничения

Класс `WMS` не должен:

- управлять конвейерами;
- перемещать товары;
- изменять состояние товара;
- собирать статистику;
- управлять контейнерами.

---

## Зависимости

---

## Примечания

В рамках симуляции `WMS` является программной имитацией внешней складской системы. В реальном проекте вместо нее может использоваться REST API, база данных или другой внешний сервис.
