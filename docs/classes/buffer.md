# Buffer

## Назначение (Purpose)

Класс `Buffer` моделирует промежуточный буфер сортировочной системы. Предназначен для временного хранения товаров до момента, когда они смогут продолжить движение по маршруту.

---

## Ответственность (Responsibilities)

Класс `Buffer` отвечает за:

- временное хранение товаров;
- прием товаров от конвейеров и сортировщиков;
- выдачу товаров по команде контроллера;
- хранение информации о своей загрузке;
- уведомление контроллера о заполнении и освобождении буфера.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `buffer_id` | int | Уникальный идентификатор буфера |
| `capacity` | int | Максимальная вместимость |
| `items` | list[Item] | Товары, находящиеся в буфере |
| `status` | BufferStatus | Текущее состояние буфера |
| `is_full` | bool | Признак заполнения буфера |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `add_item()` | Добавить товар в буфер |
| `release_item()` | Выдать товар из буфера |
| `is_available()` | Проверить наличие свободного места |
| `report_status()` | Передать состояние контроллеру |
| `report_error()` | Сообщить об ошибке |

---

## Взаимодействие

### Получает данные от

- Controller
- Conveyor
- Sorter

### Передает данные

- Controller
- Conveyor

---

## Алгоритм работы

1. Получает товар.
2. Проверяет наличие свободного места.
3. Помещает товар в очередь.
4. Ожидает команду контроллера.
5. Передает товар обратно на конвейер.

---

## Возможные ошибки

- переполнение буфера;
- невозможность добавить товар;
- невозможность выдать товар;
- потеря связи с контроллером.

---

## Ограничения

Класс `Buffer` не должен:

- выбирать маршрут товара;
- изменять состояние товара;
- обращаться к WMS;
- управлять конвейерами;
- собирать статистику.

---

## Зависимости

Класс использует:

- Item
- Controller
- Conveyor
- Sorter

---

## Примечания

`Buffer` используется только как временное хранилище. Он не принимает решений о дальнейшей судьбе товара. Решение о выдаче товара принимает `Controller`.
