# Sensor

## Назначение (Purpose)

Класс `Sensor` моделирует датчик сортировочной системы. Предназначен для обнаружения товаров в контрольных точках и передачи информации контроллеру о происходящих событиях.

---

## Ответственность (Responsibilities)

Класс `Sensor` отвечает за:

- обнаружение товара;
- определение факта прохождения товара;
- передачу информации контроллеру;
- хранение собственного состояния;
- регистрацию ошибок датчика.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `sensor_id` | int | Уникальный идентификатор датчика |
| `position` | str | Местоположение датчика |
| `is_active` | bool | Состояние датчика |
| `detection_count` | int | Количество обнаруженных товаров |
| `status` | SensorStatus | Текущее состояние датчика |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `detect_item()` | Обнаружить товар |
| `send_signal()` | Передать сигнал контроллеру |
| `report_status()` | Сообщить свое состояние |
| `report_error()` | Сообщить об ошибке |

---

## Взаимодействие

### Получает данные от

- Conveyor
- Item

### Передает данные

- Controller

---

## Алгоритм работы

1. Ожидает появления товара.
2. Фиксирует прохождение товара.
3. Передает сигнал контроллеру.
4. Возвращается в режим ожидания.

---

## Возможные ошибки

- отказ датчика;
- ложное срабатывание;
- отсутствие сигнала;
- потеря связи с контроллером.

---

## Ограничения

Класс `Sensor` не должен:

- изменять состояние товара;
- управлять конвейером;
- принимать решения о маршрутизации;
- обращаться к WMS;
- собирать статистику.

---

## Зависимости

Класс использует:

- Item
- Controller
- Conveyor

---

## Примечания

`Sensor` является источником событий системы. Он только фиксирует факт прохождения товара и уведомляет об этом контроллер. Любые решения принимаются исключительно классом `Controller`.
