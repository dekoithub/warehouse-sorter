# Conveyor

## Назначение (Purpose)

Класс `Conveyor` моделирует конвейер сортировочной системы. Предназначен для перемещения товаров между узлами сортировочного комплекса по командам контроллера.

---

## Ответственность (Responsibilities)

Класс `Conveyor` отвечает за:

- перемещение товаров;
- хранение информации о своем состоянии;
- хранение текущей скорости движения;
- хранение списка находящихся на нем товаров;
- передачу информации о состоянии контроллеру;
- уведомление о возникновении ошибок.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `conveyor_id` | int | Уникальный идентификатор конвейера |
| `speed` | float | Скорость движения |
| `capacity` | int | Максимальное количество товаров |
| `items` | list[Item] | Товары на конвейере |
| `status` | ConveyorStatus | Текущее состояние |
| `is_available` | bool | Доступность конвейера |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `accept_item()` | Принять товар на конвейер |
| `move_items()` | Переместить товары |
| `release_item()` | Передать товар следующему модулю |
| `change_speed()` | Изменить скорость |
| `stop()` | Остановить конвейер |
| `start()` | Запустить конвейер |
| `report_status()` | Сообщить состояние контроллеру |

---

## Взаимодействие

### Получает данные от

- Controller

### Передает данные

- Controller
- Sensor
- Sorter
- Buffer
- OutputBin

---

## Алгоритм работы

1. Получает команду от Controller.
2. Принимает товар.
3. Перемещает товар.
4. Передает товар следующему модулю.
5. Сообщает контроллеру о завершении операции.

---

## Возможные ошибки

- перегрузка;
- остановка конвейера;
- превышена вместимость;
- механическая неисправность;
- блокировка товара.

---

## Ограничения

Класс `Conveyor` не должен:

- выбирать маршрут товара;
- взаимодействовать с WMS;
- принимать решения о сортировке;
- изменять характеристики товара;
- собирать статистику.

---

## Зависимости

Класс использует:

- Item
- Controller
- Sensor
- Sorter
- Buffer
- OutputBin

---

## Примечания

`Conveyor` отвечает только за транспортировку товаров. Все решения о том, куда должен двигаться товар, принимает класс `Controller`. Конвейер выполняет только полученные команды.
