# Sorter

## Назначение (Purpose)

Класс `Sorter` моделирует сортировочный модуль системы. Предназначен для изменения направления движения товара в соответствии с маршрутом, назначенным контроллером.

---

## Ответственность (Responsibilities)

Класс `Sorter` отвечает за:

- изменение направления движения товара;
- прием товара с конвейера;
- передачу товара на следующий участок;
- хранение собственного состояния;
- уведомление контроллера о выполнении операции;
- регистрацию ошибок сортировки.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `sorter_id` | int | Уникальный идентификатор сортировщика |
| `status` | SorterStatus | Текущее состояние сортировщика |
| `current_direction` | int | Активное направление |
| `supported_directions` | list[int] | Поддерживаемые направления |
| `is_available` | bool | Доступность сортировщика |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `accept_item()` | Принять товар |
| `sort_item()` | Изменить направление движения товара |
| `send_item()` | Передать товар следующему модулю |
| `change_direction()` | Переключить направление |
| `report_status()` | Сообщить состояние контроллеру |
| `report_error()` | Сообщить об ошибке |

---

## Взаимодействие

### Получает данные от

- Conveyor
- Controller
- Item

### Передает данные

- Conveyor
- Buffer
- OutputBin
- Controller

---

## Алгоритм работы

1. Получает товар.
2. Получает команду контроллера.
3. Переключает направление.
4. Передает товар следующему модулю.
5. Сообщает контроллеру об успешном завершении операции.

---

## Возможные ошибки

- невозможность переключения направления;
- механическая неисправность;
- отсутствие товара;
- блокировка механизма;
- потеря связи с контроллером.

---

## Ограничения

Класс `Sorter` не должен:

- выбирать маршрут товара;
- взаимодействовать с WMS;
- изменять характеристики товара;
- принимать решения о повторной сортировке;
- собирать статистику.

---

## Зависимости

Класс использует:

- Item
- Controller
- Conveyor
- Buffer
- OutputBin

---

## Примечания

`Sorter` выполняет только физическое изменение направления движения товара. Все решения о том, куда необходимо направить товар, принимает класс `Controller`.
