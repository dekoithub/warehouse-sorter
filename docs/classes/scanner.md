# Scanner

## Назначение (Purpose)

Класс `Scanner` моделирует сканер штрихкодов сортировочной системы. Предназначен для считывания идентификатора товара и передачи результата контроллеру для дальнейшей обработки.

---

## Ответственность (Responsibilities)

Класс `Scanner` отвечает за:

- обнаружение товара в зоне сканирования;
- считывание штрихкода;
- проверку успешности сканирования;
- передачу результата контроллеру;
- регистрацию ошибки при невозможности считывания.

---

## Поля (Attributes)

| Поле | Тип | Описание |
|------|-----|----------|
| `scanner_id` | int | Идентификатор сканера |
| `is_active` | bool | Состояние сканера |
| `error_rate` | float | Вероятность ошибки считывания |
| `scan_count` | int | Количество выполненных сканирований |

---

## Методы (Methods)

| Метод | Назначение |
|--------|------------|
| `scan()` | Считывает штрихкод товара |
| `detect_item()` | Проверяет наличие товара |
| `send_result()` | Передает результат контроллеру |
| `report_error()` | Сообщает об ошибке сканирования |

---

## Взаимодействие

### Получает данные от

- Sensor
- Item

### Передает данные

- Controller

---

## Алгоритм работы

1. Ожидает появления товара.
2. Получает сигнал от датчика.
3. Выполняет сканирование.
4. Проверяет успешность считывания.
5. Передает результат контроллеру.
6. При ошибке сообщает контроллеру.

---

## Возможные ошибки

- штрихкод не читается;
- поврежден штрихкод;
- отсутствует товар;
- сканер недоступен.

---

## Ограничения

Класс `Scanner` не должен:

- выбирать маршрут товара;
- изменять состояние товара;
- управлять конвейерами;
- обращаться к WMS;
- собирать статистику.

---

## Зависимости

Класс использует:

- Item
- Sensor
- Controller

---

## Примечания

`Scanner` является источником информации о товаре. После успешного считывания его задача завершается, а дальнейшая обработка полностью передается классу `Controller`.
